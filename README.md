# QR Note Board

A simple offline note board that turns a note into a QR code. Great for sharing Wi-Fi instructions, event details, short URLs, or text between devices.

## Features
- Create, edit, and delete notes
- Search notes instantly
- Generate QR codes from note text
- Copy note text
- Local persistence
- Responsive UI

## Run
Open `index.html`.

The QR library is loaded from a CDN, so QR generation needs internet access. The notes themselves remain in local storage.

## Tech
HTML, CSS, Vanilla JavaScript, QRCode.js CDN.
